# PYNQ-ZU DPU Vitis handoff

`build_vitis_dpu_platform.py` is the Vitis Embedded 2024.2 handoff check for
the XSA generated by `fpga/export_pynq_zu_dpu_xsa.tcl`.

```powershell
$env:PYNQ_ZU_DPU_XSA = 'C:\pynq_zu_dpu_native_build\pynq_zu_dpu_b512.xsa'
$env:PYNQ_ZU_DPU_VITIS_WORKSPACE = 'C:\pynq_dpu_vitis'
& 'C:\Xilinx_Embedded_2024_2\Vitis\2024.2\bin\vitis.bat' -s build_vitis_dpu_platform.py
```

The workspace must be a new, short Windows path. The script builds an A53
`standalone` platform so Vitis validates the XSA, processor and BSP handoff.
It intentionally does not create a DPU inference application: a Logitech C270
uses PS USB and Linux UVC/V4L2, and native DPU execution requires a matching
Linux device tree, CMA, DPU driver, VART runtime, B512 `arch.json`, and INT8
`.xmodel`. The generated XPFM/workspace is a local build artifact, not Git
content.
